Using Pulpo

The screen

Three columns and a bottom line.

Columns

ColumnPanelsGo there
LeftWorkspaces, Sessions⌘p w, ⌘p s
MiddleThe session's terminals⌘p t
RightFiles, Changes⌘p f, ⌘p c

The panel with the focus has the accent border. A click also moves the focus; hovering doesn't.

Full screen

Opening a file in Files or Changes (⏎ or a double click) gives that panel everything right of the sidebar, terminal included, with the keys on the file.

  • esc puts the keys on the tree; moving in it shows each file.
  • ⏎ or tab goes back into the file.
  • esc on the tree goes back to the three columns.

Hide and resize

  • ⌘p < hides or shows the left side, ⌘p > the right side. Going to a hidden panel shows it again.
  • Drag a border to resize: the sidebar's, the right side's, and the line between a tree and its file.

Bottom line

Names you type (a new file, a session), questions (answer y, or click yes; anything else is no) and short messages.
