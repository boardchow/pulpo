Get started

Quick start

From the first run to reviewing what an agent did.

  1. Open Pulpo in a repository. 
    cd ~/code/my-app
pulpo

    The repository joins your workspaces and a shell opens in the middle. Keys go to it.

  2. Start an agent. Type claude in that shell and give it a task.
  3. Use the prefix. Press ⌘p, let go, then a key. ⌘p ? lists them all. ⌘p n opens another terminal tab (try make run there); ⌘p [ and ⌘p ] go between tabs.
  4. Give the next task its own copy. ⌘p s goes to Sessions, ⌘p n asks for a name. You get a shell in a fresh copy of the repository right away, with its own Docker containers and ports set up in the background. Start claude there too.
  5. See who needs you. A ◆ marks the session and tab waiting for you, and Ghostty sends a notification. ⌘p a goes to the one that has waited longest.
  6. Review the work. ⌘p c goes to Changes: every file the session changed. ⏎ opens a file over the right side, with its changes in place. esc goes back to the tree, esc again to the three columns.
  7. Quit. ⌘p q quits; the agents keep working. Run pulpo to come back. ⌘p Q stops everything.
