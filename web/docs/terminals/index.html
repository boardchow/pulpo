Using Pulpo

Terminals

Each session has its terminals, as tabs. They run in a background server, so quitting Pulpo doesn't stop them.

Tabs

New terminal (a shell)⌘p n in the terminal, or ⌘p t in a session without oneClick +

Close⌘p x

Closing asks first when a program is running in it. A terminal belongs to the session it was started in.

Keys

Every key goes to the program, except the prefix. Claude Code uses ⌃b to background a command: press ⌃b ⌃b.

Mouse

  • Wheel: scrolls back through the output. In full-screen programs (less, vim), it sends arrow keys.
  • Drag: selects text; it's copied when you let go.
  • Ctrl-click: opens a link in the browser, or a path like src/app.rs:120 in Files at that line.
  • A program that takes the mouse itself gets the clicks; hold shift to select anyway.

Quitting, rebooting, updating

  • ⌘p q quits Pulpo. Terminals keep running; pulpo brings them back as you left them.
  • After a reboot, Pulpo opens them again in their folders, and resumes the Claude sessions that were running (with claude --resume; this needs the hooks).
  • Updating Pulpo doesn't stop them either.
  • ⌘p Q stops them all: Ctrl-C first, so dev servers free their ports and docker compose up stops its containers, then, after up to 10 seconds, a hang-up.
