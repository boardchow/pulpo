Command line

Everything else is in the app.

CommandDoes
pulpo [path]Opens Pulpo. A repository at path (the current folder by default) joins the workspaces.
pulpo hooks installAdds Pulpo's hooks to Claude Code. --dry-run shows what would change.
pulpo hooks statusShows which hooks are installed, outdated or missing.
pulpo hooks removeTakes them out. --dry-run works here too.
pulpo hooksPrints the hooks, to add by hand.
pulpo doctorChecks that the prefix reaches Pulpo and that the hooks are installed.
pulpo keytestShows what Pulpo receives for each key you press; q stops.
pulpo serveThe server that keeps terminals running. Pulpo starts it.
pulpo emitRecords a hook event. The hooks call it.
