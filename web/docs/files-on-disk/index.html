Reference

Files on disk

Where Pulpo keeps its settings and state.

Settings

PathHolds
~/.config/pulpo/workspacesYour repositories, one path per line
~/.config/pulpo/keys.tomlThe prefix
~/.config/pulpo/config.tomlThe theme
~/.config/pulpo/repos/<repo>.tomlHow the repository's task sessions are set up

State

PathHolds
~/.local/state/pulpo/server/sockThe server's socket (private to you; Pulpo never listens on the network)
~/.local/state/pulpo/server/logThe server's log
~/.local/state/pulpo/server/layout.jsonWhere you were and what was open, to come back to it
~/.local/state/pulpo/sessions.jsonThe task sessions
~/.local/state/pulpo/events.jsonlWhat the Claude hooks reported
~/.local/state/pulpo/logs/Task session setup and removal logs

A Pulpo started inside a Pulpo terminal uses server-nested/ instead, so it doesn't show itself.

Task sessions

<repo>.sessions/<name>, next to the repository.
