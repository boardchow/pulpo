Pulpo

A terminal for running several coding agents side by side on a Mac. Each task gets its own copy of the repository, you see which agent needs you, and the files and what changed sit next to the terminals.

  • Left: your repositories (workspaces) and their sessions. A mark shows which one is working (spinner) or waiting for you (◆).
  • Middle: the session's terminals, as tabs. Claude Code, a dev server, a shell.
  • Right: the session's files, and what it changed.

Everything is one prefix away, from anywhere, terminals included: ⌘p then a key, or the mouse. Terminals keep running when you quit Pulpo, and come back after a reboot.
