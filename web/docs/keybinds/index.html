Keybinds

Press the prefix, let go, then a key. The prefix works everywhere, in terminals and popups too.

The prefix is ⌘p or ⌃b. Pressing ⌃b twice sends one to the program. If no key follows within 3 seconds, nothing happens. To change it, see Configuration.
