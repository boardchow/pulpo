Using Pulpo

Workspaces and sessions

A workspace is a repository; a session is one checkout of it, with its own terminals, files and changes.

Workspaces

Opening pulpo inside a repository adds it. To add another, ⌘p w then ⌘p n: pick from the git repositories in your home folder, or type a path.

⌘p x in Workspaces takes a repository off the list. Its files stay.

Sessions

The current workspace's sessions:

SessionWhat it is
mainThe repository itself.
A git worktreeShown if the repository has worktrees. Pulpo doesn't create or delete them.
A task sessionA copy of the repository for one task. See Task sessions.

Each row shows the session's state, its name, its number of uncommitted changes (±3), the web port of a task session (:20000), and under the name its branch, or setting up / setup failed.

Selecting a session (click, or arrows in Sessions) puts its terminals, files and changes on screen. Pulpo remembers the last session of each workspace.
