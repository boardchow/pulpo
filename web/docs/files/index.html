Using Pulpo

Files

The session's files as a tree, the selected one beside it. Read, search, edit, create, rename, delete.

Tree

↑ ↓ move, ← → fold and unfold, ⏎ opens a folder or a file. The selected file shows on the right. Names are colored by git status: green new, blue changed, red deleted. Files git ignores are left out.

⏎ on a file opens it full screen: see Full screen. Long lines scroll sideways with a trackpad swipe, shift + wheel, or ← → in the file.

Search

⌘p / opens the search over whatever is on screen.

  • It starts on the file tree; typing filters it by name (fuzzy).
  • tab searches inside the files instead (two characters or more; case-insensitive unless you type a capital).
  • ⏎ opens the file full screen, on the line found.

Edit

⌘p e edits the selected file, full screen, in Pulpo's editor. The keys are the usual ones:

KeysDoes
⌘s or ⌃sSave (you stay in the editor)
escLeave; with unsaved changes, press it twice to throw them away
shift + movesSelect
⌘c ⌘x ⌘v, ⌘aCopy, cut, paste, select all
⌘z, ⌘⇧zUndo, redo
⌘f, ⌘gFind, next match

If an agent changes the file while it's open and you haven't changed it, the editor takes the new version.

Create, rename, delete

KeysDoes
⌘p nNew file in the selected folder. A path makes its folders; a name ending in / makes a folder. A new file opens in the editor.
⌘p rRename the selected file or folder.
⌘p dDelete it, after asking. It says whether git can bring it back.
